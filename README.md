## 🛠 Công Nghệ Sử Dụng

- **Frontend**: HTML5, CSS3, Bootstarp
- **Storage**: MySQL
- **Styling**: Custom CSS với CSS Variables
- **Icons**: Emoji và Unicode characters
- **Responsive**: Mobile-first responsive design

## 🚀 Hướng Dẫn Chạy Dự Án

1. Chạy local Xampp

Mở Xampp ở mục Apache nhấn Start

Mở trình duyệt truy cập: http://localhost/tên project

💾 Quản Lý Dữ Liệu
Dự án sử dụng MySQL để lưu trữ dữ liệu

Cấu trúc dữ liệu:

categories: Danh mục sản phẩm

products: Sản phẩm

users: Người dùng

orders: Đơn hàng

orderDetails: Chi tiết đơn hàng

cart: Giỏ hàng

🎨 Thiết Kế & UX
Màu sắc chính: Đỏ và Trắng

Typography: Segoe UI system font stack

Layout: Grid & Flexbox responsive

Components: Card-based design

Interactions: Smooth transitions và hover effects

📱 Responsive Design
Desktop: > 1200px

Tablet: 768px - 1199px

Mobile: < 767px

Orientation: Hỗ trợ cả portrait và landscape

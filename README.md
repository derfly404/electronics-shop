# electronics-shop
shop thương mại điện tử

Website bán đồ điện tử được xây dựng bằng PHP thuần với đầy đủ tính năng từ frontend đến backend admin.

## 🚀 Tính Năng Nổi Bật

### Frontend (Khách hàng)
- ✅ **Trang chủ** - Hiển thị sản phẩm nổi bật, danh mục
- ✅ **Danh sách sản phẩm** - Lọc theo danh mục, khoảng giá, tìm kiếm
- ✅ **Chi tiết sản phẩm** - Hiển thị thông tin và các biến thể
- ✅ **Giỏ hàng** - Thêm/sửa/xóa sản phẩm
- ✅ **Thanh toán** - Form nhập thông tin giao hàng
- ✅ **Đăng ký/Đăng nhập** - Xác thực người dùng
- ✅ **Trang cảm ơn** - Sau khi thanh toán thành công

### Backend (Admin)
- ✅ **Quản lý danh mục** - CRUD danh mục sản phẩm
- ✅ **Quản lý sản phẩm** - CRUD sản phẩm và biến thể
- ✅ **Quản lý đơn hàng** - Xem, cập nhật trạng thái đơn hàng
- ✅ **Quản lý khách hàng** - Xem thông tin khách hàng
- ✅ **Thống kê** - Doanh thu, sản phẩm bán chạy, tồn kho

## 🛠 Công Nghệ Sử Dụng

- **Frontend**: HTML5, CSS3, Bootstarp
- **Storage**: MySQL
- **Styling**: Custom CSS với CSS Variables
- **Icons**: Emoji và Unicode characters
- **Responsive**: Mobile-first responsive design

## 🚀 Hướng Dẫn Chạy Dự Án

1. Chạy local Xampp

Mở Xampp ở mục Apache nhấn Start

Mở trình duyệt truy cập: http://localhost/tên project

💾 Quản Lý Dữ Liệu
Dự án sử dụng MySQL để lưu trữ dữ liệu

products: Sản phẩm

users: Người dùng

orders: Đơn hàng

orderDetails: Chi tiết đơn hàng

cart: Giỏ hàng
